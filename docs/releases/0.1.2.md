| Platform | Release asset |
| --- | --- |
| Windows x64 | `mr-financer-v0.1.2-windows-x64.exe` |
| macOS Apple Silicon | `mr-financer-v0.1.2-macos-arm64.tar.gz` |
| macOS Intel | `mr-financer-v0.1.2-macos-x64.tar.gz` |
| Linux x64 | `mr-financer-v0.1.2-linux-x64.tar.gz` |

Each download bundles Python, the app, and headless Chromium for live-source lookups. GitHub Actions starts each executable and checks the browser workspace and all three document export formats before publishing. Use `SHA256SUMS` to verify a download.

## Start the app

On Windows, run the `.exe` from a writable folder. On macOS and Linux, extract the archive, open a terminal in that folder, and run `./mrfinancer`. The app opens your browser at `http://127.0.0.1:8765/`. Keep the terminal open while using the app. Use `--no-browser` to print the local address or `--port 8766` to use a different port.

The Windows executable has no publisher signature. The macOS builds are ad hoc signed and have no Apple notarization. Windows or macOS may ask you to confirm the first launch.

The Linux executable was tested on Ubuntu 22.04 x64. Minimal Linux installs may need the system libraries required by headless Chromium. The executables read optional connector settings from `.env` in the working directory.
