## New in 0.2.0

In **Ideation → Review financial records**, select companies and click **Fetch records** to explore the figures returned by their registries.

- **Financial bar charts** show each reportable figure with its period, currency or unit, source, and any validation notes. Open **Financial figures and sources** to see the full table.
- **Balance sheet pie charts** show cash versus other assets and liabilities versus equity when the filing has matching figures. Switch dates when multiple balance sheets are available.
- **Ask about these figures** answers questions about a company’s fetched records, such as “What was revenue in 2024?”, “How did revenue change from 2024 to 2025?”, and “What share of assets was cash?” Answers cite the records used.

The charts and Q&A run locally in the browser without an additional API key or paid service.

## Download a native executable

| Platform | Release asset |
| --- | --- |
| Windows x64 | `mr-financer-v0.2.0-windows-x64.exe` |
| macOS Apple Silicon | `mr-financer-v0.2.0-macos-arm64.tar.gz` |
| macOS Intel | `mr-financer-v0.2.0-macos-x64.tar.gz` |
| Linux x64 | `mr-financer-v0.2.0-linux-x64.tar.gz` |

The builds include Python and headless Chromium. Use `SHA256SUMS` to verify your download.

Run the Windows executable from a writable folder. On macOS or Linux, extract the archive and run `./mrfinancer` from that folder. The app opens at `http://127.0.0.1:8765/`. [Setup and configuration](https://github.com/vivekchakraverty/mr-financer/blob/v0.2.0/docs/setup.md)
