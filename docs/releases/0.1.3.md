## New in 0.1.3

- **Learn** adds 24 topics for first-time founders, from customer interviews and pricing to cash flow, hiring, and growth. Each topic has three video slots and a practical assignment.
- **Find videos** searches YouTube with yt-dlp, checks for usable English captions, and ranks candidates by transcript fit, useful viewer comments, and likes per view. Replace any pick with a YouTube URL.
- **Fresh quizzes** use the selected video's transcript. Each attempt has six multiple-choice questions, three fill-in-the-blank questions with choices, and one three-pair match. Results include explanations or correct matches and links to the relevant video timestamps.
- **Local progress** keeps your scores and past attempts in Mr. Financer. The hosted CPU service accepts a Hugging Face read token from your own account.

To use Learn, install [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation) and make it available on your PATH. Open **Learn → Connect quiz service** and enter a [Hugging Face read token](https://huggingface.co/settings/tokens). Generation on the shared CPU can take a minute or two.

## Download a native executable

| Platform | Release asset |
| --- | --- |
| Windows x64 | `mr-financer-v0.1.3-windows-x64.exe` |
| macOS Apple Silicon | `mr-financer-v0.1.3-macos-arm64.tar.gz` |
| macOS Intel | `mr-financer-v0.1.3-macos-x64.tar.gz` |
| Linux x64 | `mr-financer-v0.1.3-linux-x64.tar.gz` |

The builds include Python and headless Chromium. GitHub Actions verifies the packaged workspace, Learn curriculum, and document exports on each platform. Use `SHA256SUMS` to verify your download.

Run the Windows executable from a writable folder. On macOS or Linux, extract the archive and run `./mrfinancer` from that folder. The app opens at `http://127.0.0.1:8765/`. Windows and macOS may ask you to confirm the first launch. [Setup and configuration](https://github.com/vivekchakraverty/mr-financer/blob/v0.1.3/docs/setup.md)
